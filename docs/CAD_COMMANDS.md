# CardCraft CAD 命令行交互手册 (CAD Command Manual)

CardCraft 的交互系统受到 AutoCAD / Vim 命令行的启发，遵循**“极简缩写动词 + 数字/代号参数”**的设计规范。

---

## 一、 指令语法规范

所有命令由命令行底部输入，大小写不敏感，参数间使用空格隔开。

```text
[动词缩写或全称] [参数1] [参数2] ...
```

---

## 二、 核心操作指令一览

### 1. `s` / `stack`（堆叠）
* **语法**：`s <from-id> <to-id>`
* **参数**：
  * `<from-id>`：被移动卡栈的数字编号。
  * `<to-id>`：目标卡栈的数字编号。
* **行为**：
  * 将源卡栈中的所有卡牌按顺序堆叠到目标卡栈的顶部。
  * 源卡栈被清空并回收。
  * 系统自动重新扫描目标卡栈，若符合已知合成配方，立即启动倒计时进度条。
* **示例**：
  ```text
  s 1 2       ; 将 1 号槽位的村民压到 2 号槽位的浆果丛上进行采摘
  s 4 5       ; 将 4 号槽位的木头堆到 5 号槽位
  ```

---

### 2. `u` / `unstack`（拆解 / 弹卡）
* **语法**：`u <slot-id>`
* **参数**：
  * `<slot-id>`：目标卡栈的数字编号。
* **行为**：
  * 从指定卡栈的顶部弹出一张卡牌。
  * 自动为该卡牌分配一个全新的空闲槽位。
  * 原卡栈如果正在进行合成，且被弹出的卡牌是关键原料，进度条会立即中断重置。
* **示例**：
  ```text
  u 2         ; 把 2 号槽位顶部的村民抽离出来
  ```

---

### 3. `m` / `move`（移动 / 槽位整理）
* **语法**：`m <from-id> <to-id>`
* **参数**：
  * `<from-id>`：当前卡栈编号。
  * `<to-id>`：目标空闲槽位编号。
* **行为**：
  * 将整栈卡牌移动到指定的新编号位置（目标位置必须为空闲）。
  * 适用于整理桌面、给重要生产建筑留出空位。
* **示例**：
  ```text
  m 3 10      ; 将 3 号槽位整体挪到 10 号槽位
  ```

---

### 4. `b` / `buy`（购买卡包）
* **语法**：`b <pack-id>`
* **可用卡包**：
  * `basic`（基础包，3G）：产出木头、石头、浆果丛、金币。
  * `food`（农业食物包，5G）：产出大量浆果、苹果与植物。
* **行为**：
  * 检查黄金是否充足，扣除对应货币后在新的空闲槽位生成对应的未拆封卡包（如 `Pack:Basic`）。
* **示例**：
  ```text
  b basic     ; 花费 3G 购买基础包
  b food      ; 花费 5G 购买食物包
  ```

---

### 5. `o` / `open`（拆开卡包）
* **语法**：`o <slot-id>`
* **参数**：
  * `<slot-id>`：卡包所在的槽位编号。
* **行为**：
  * 消耗卡包卡牌，并随机在场上弹出 3 张资源卡牌。
* **示例**：
  ```text
  o 6         ; 拆开 6 号槽位上的卡包
  ```

---

### 6. `x` / `sell`（出售卡牌变现）
* **语法**：`x <slot-id>`
* **参数**：
  * `<slot-id>`：要出售的卡栈编号。
* **行为**：
  * 卖掉该槽位最顶部的单张卡牌，按其价值增加黄金储备；卡牌被销毁。
  * *注：村民（Villager）与婴儿（Baby）价值为 0G，无法被出售。*
* **示例**：
  ```text
  x 4         ; 卖掉 4 号槽位的木头，换取 1G
  ```

---

### 7. `w` / `wait`（时间快进）
* **语法**：`w [seconds]`
* **行为**：
  * 瞬间推进游戏引擎流逝指定的秒数（默认 1 秒）。
  * 适用于快速完成长周期的建造或繁殖配方。
* **示例**：
  ```text
  w           ; 推进 1 秒
  w 5         ; 推进 5 秒
  w 30        ; 推进 30 秒并立即触发月度结算
  ```

---

### 8. `p` / `pause`（暂停与继续）
* **语法**：`p`
* **行为**：
  * 切换世界的运行状态（`RUNNING` <-> `PAUSED`）。暂停时配方进度与月度计时器停止计时。

---

### 9. `h` / `help`（查看帮助）
* **语法**：`h` 或 `?`
* **行为**：在事件日志区输出指令帮助提示。

---

### 10. `q` / `quit`（退出游戏）
* **语法**：`q`、`quit` 或 `exit`
* **行为**：安全还原终端模式并退出。

---

## 三、 特殊能力：Scheme 动态求值（God Mode）

任何以**左括号 `(`** 开头的输入，引擎会自动识别为原生的 **Steel Scheme** 表达式，并在当前游戏上下文中直接求值！

* **任意刷卡**：
  ```scheme
  (spawn-card! "Apple")
  (spawn-card! "Villager")
  ```
* **修改金币**：
  ```scheme
  (set! *world-gold* 999)
  ```
* **手动触发月相结算**：
  ```scheme
  (engine-tick! 35.0)
  ```

## 四、 键盘控制快捷键

| 按键 | 功能 |
| :--- | :--- |
| **`Enter`** | 提交当前命令并执行 |
| **`Backspace`** | 删除光标左侧字符 |
| **`Delete`** | 删除光标所在字符 |
| **`←` / `→`** | 左右微调输入光标位置 |
| **`Home` / `End`** | 快速跳转至命令首 / 尾 |
| **`↑` / `↓`** | 向上 / 向下翻查历史输入记录 |
| **`Ctrl + C`** | 强制终止并退出游戏 |
